# SewaBook – Hospital Appointment System

SewaBook is a Flutter-based mobile application developed to simplify hospital appointment booking and management. The application allows patients to easily schedule appointments with doctors based on their availability across different clinics and hospitals.

---

##  Features

-  Book hospital appointments online
-  Browse doctors and medical specialties
-  Easy-to-use and responsive interface
-  Cross-platform mobile application
-  Simplified appointment management
-  Fast and smooth user experience

---

##  Getting Started

### Prerequisites

Before running the project, make sure you have installed:

- Flutter SDK
- Android Studio or VS Code
- Git

Check Flutter installation:

```bash
flutter doctor
```

---

##  Installation

Clone the repository:

```bash
git clone https://github.com/Barshadangi/flutter-hospitalappointment-app.git
```

Navigate to the project directory:

```bash
cd flutter-hospitalappointment-app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
